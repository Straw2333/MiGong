# 小兔找萝卜 · 3岁+ 宝宝迷宫

一款给 3 岁以上宝宝玩的浏览器迷宫小游戏：牵着小白兔穿过花园灌木丛，找到大萝卜。
无广告、无内购、无需联网，双击 `index.html` 就能玩。

---

## 一、为什么这样设计

3 岁左右的宝宝有几个特点，游戏里每一条都对应了具体设计：

| 宝宝的实际情况 | 游戏里的做法 |
|---|---|
| 手指控制还不精细，容易点歪 | 手指**按住屏幕任意位置**拖动即可带小兔走，不用点中兔子；碰撞很宽容，贴墙会自动滑行 |
| 不识字、读不懂规则 | 几乎不依赖文字：目标（萝卜）、可收集物（星星）、奖励（贴纸）都用画面表达 |
| 怕失败、容易受挫 | **没有失败、没有倒计时、没有生命值**，走错路随时可以回头；终点永远在，不会被夺走 |
| 注意力短，需要即时反馈 | 每一步都有轻微弹跳动画；吃到星星有音效和金色粒子；碰到灌木有软软的"咚"声 |
| 容易在岔路口迷路 | 关卡一开始没有死胡同（通道成环），后期才慢慢出现少量死路；卡住 9 秒后自动出现金色虚线指路 |
| 对声音和颜色敏感 | 明亮柔和的糖果色、圆角灌木、圆角大按钮；轻快的木琴音效 + 若隐若现的背景音乐 |
| 喜欢重复和掌控感 | 有**主页选关**，想重玩哪一关就点哪一关；通关进度、星星和贴纸都会自动保存 |

## 二、核心玩法

1. 打开游戏先到**主页**：点大按钮"开始玩"会接着上次的关卡；也可以直接点下面的关卡卡片选关。
2. **牵着兔子走**：手指（或鼠标）按住屏幕，兔子会朝手指方向移动；也可以短按一个位置，兔子自己走过去。
3. 路上可以顺路吃 **3 颗星星**（第 1 关 2 颗，不吃也能过关）。
4. 到达 **大萝卜** 即过关，撒彩带 + 奖励音效，点"下一关"继续，或"回主页"去选关。
5. 电脑上也可以用 **方向键 / WASD** 控制。

> 关卡不会失败，所以宝宝可以放心乱走；家长也不需要一直陪着。

## 三、星星有什么用：贴纸册

星星不只是好看——**每一颗星星都会被存进"星星贴纸册"**，攒够一定数量就解锁一张贴纸：

| 累计星星 | 解锁贴纸 |
|---|---|
| 3 颗 | 🦋 蝴蝶 |
| 6 颗 | 🌷 小花 |
| 9 颗 | 🐞 瓢虫 |
| 12 颗 | 🌈 彩虹 |
| 15 颗 | 🐥 小鸡 |
| 18 颗 | 🍄 蘑菇 |
| 21 颗 | 🍰 蛋糕 |
| 23 颗 | 👑 皇冠 |

- 第 1 关有 2 颗星星，第 2–8 关各 3 颗，前 8 关一共正好 23 颗，集满 23 颗就能拿齐全部 8 张贴纸。
- 第 9 关以后是无限关卡，星星继续计入贴纸册（集满后不再增加）。
- 主页最下方就是贴纸册：没解锁的是灰色剪影，解锁后会变彩色并轻轻弹一下；过关时如果恰好解锁新贴纸，会弹出"获得新贴纸！"的横幅和专属音效。
- 每关收集的星星**每次都会累加**，所以重复玩同一关也能继续攒贴纸；关卡卡片上显示的是这一关的最好成绩。

## 四、主页与选关

- 主页显示：游戏的开始按钮、8 张关卡卡片、星星总数（如 `3/23`）和贴纸册。
- 关卡卡片：
  - 玩过的关卡会变绿并出现 ✓，下面显示最好成绩（金色小星星）；
  - **当前该玩的关卡**有金色光晕并轻轻呼吸，一眼就能找到；
  - 想重玩前面的关卡，直接点卡片即可。
- 第 8 关之后还有无限关卡：从第 8 关点"下一关"就会一直玩下去，难度不再增加，只变换布局。

## 五、难度曲线

| 关卡 | 迷宫规模 | 特点 |
|---|---|---|
| 1 | 7×7 格（手工） | 一条宽宽的环形路，没有死胡同，几乎没有岔路 |
| 2 | 9×8 格（手工） | 出现几条支路和 1 个很短的死胡同 |
| 3–4 | 9×7 格（随机） | 环形通道，少量岔路，星星引导探索 |
| 5–6 | 11×7 格（随机） | 岔路增多，开始出现短死胡同 |
| 7 | 11×9 格（随机） | 规模变大，需要记住走过的路 |
| 8+ | 13×9 格（随机，封顶） | 难度到此为止，之后只变换布局，不无限变难 |

- 随机迷宫使用"递归回溯 + 编织（braid）"算法：先保证起点到终点连通，再按关卡把死胡同打通成环路，越靠前的关卡越"友好"。
- 星星总是放在从起点走 3 步以上、彼此分散的位置，鼓励宝宝多探索，但绝不影响过关。

## 六、宝宝友好细节

- **自动指路**：如果兔子 9 秒内几乎没有移动，屏幕上会出现一条闪烁的金色虚线，一直通到大萝卜，6 秒后自动消失。宝宝一走动就会重新计时。
- **贴墙滑行**：斜着顶到墙角时会沿着墙滑过去，而不是被卡住。
- **大按钮**：右上角声音、主页、全屏都是 46px 圆形按钮；过关按钮超大。
- **防误触**：禁用长按菜单、双击缩放、页面滚动；画布铺满全屏。
- **音效可关**：右上角小喇叭可静音，设置会记住（localStorage）。
- **全屏模式**：平板/手机上点右上角⛶，可以隐藏浏览器地址栏，更像一个 App。
- **随时回主页**：玩到一半点右上角小房子，就能回主页选别的关卡或重新开始；本关星星在过关时才结算入库，中途离开不会计入。

## 七、视觉与音效

- 场景：草地、云朵、小花、修剪整齐的灌木迷宫、奶油色小路。
- 角色：白色小兔（会眨眼、蹦跳、撞墙时轻轻压扁），橙色大萝卜（呼吸光晕）。
- 反馈：星星会旋转闪烁，收集时金色粒子四散，过关时彩带从上落下，解锁贴纸时有上扬的琶音。
- 音效全部由 Web Audio 实时合成，没有任何外部音频/图片文件，离线可用：
  - 吃星星：两声上行木琴音
  - 过关：五音上行小旋律
  - 解锁贴纸：四音上扬琶音
  - 撞墙：低低的软"咚"
  - 背景音乐：随机五声音阶的稀疏拨弦，音量很低，不吵人。

## 八、适龄与家长说明

- 建议 **3 岁以上**，在家长陪同下使用；3 岁以下宝宝可能会把设备当作磨牙玩具。
- 游戏**完全离线**：没有网络请求、没有广告、没有账号、不收集任何数据。
- 本机只写入一处 localStorage（键名 `migong.save.v1`），保存的是游戏进度和声音偏好：
  - 每关的最好星星数、累计星星数、当前关卡；
  - 声音开/关。
- 想让孩子从头开始：在浏览器开发者工具里执行 `localStorage.removeItem('migong.save.v1')` 后刷新即可。
- 建议每次游玩 10–15 分钟，休息眼睛。

## 九、运行方式

最简单：双击 `index.html`。

如果浏览器限制本地文件（一般不会），可以在本目录运行：

```bash
python -m http.server 4197
```

然后打开 <http://127.0.0.1:4197>。

## 十、技术说明

- 单文件 `index.html`，原生 HTML + CSS + Canvas 2D，无任何依赖。
- 迷宫、角色、粒子、贴纸全部程序化绘制；自适应屏幕与横竖屏，支持高清屏（devicePixelRatio）。
- 碰撞：圆形兔子简化为 AABB，与灌木格逐轴求解，稳定且不会穿墙。
- 文件结构：

```
MiGong/
├─ index.html      ← 游戏本体（打开即玩）
├─ README.md       ← 本文档
└─ .claude/launch.json  ← 本地预览配置（开发用）
```
